# 월 근무시간 계산기

한 달 필수 근무시간, 남은 근무일의 하루 평균 필요 시간, 오늘 퇴근 가능 시각을 계산하는 웹앱

- 사이트: https://wonuoh.github.io/monthly-work-hours-calculator/
- 데이터는 사용하는 브라우저(localStorage)에만 저장, 설정 메뉴에서 백업 파일 내보내기·불러오기 가능

## 주요 기능

- 연도 제한 없는 월 이동 및 공휴일 자동 계산
  - 설날·부처님 오신 날·추석은 브라우저 내장 한국 음력(Intl `dangi`)으로 계산, 미지원 브라우저는 2000~2050년 내장표 사용
  - 대체공휴일, 국회의원 선거일, 전국동시지방선거일은 법정 규칙으로 계산
- 연차(8시간)·반차(4시간)·반반차(2시간)·휴무 처리
- 주말·공휴일 근무 기록
- 출근 시각 입력 시 이달 기준 퇴근 가능 시각 계산, 퇴근 시각 입력 시 오늘 기록에 바로 반영
- 필수 근무시간 직접 입력, 점심·휴게시간, 코어타임 설정

## 필수 근무시간 계산식

`40시간 × (해당 월 일수 ÷ 7) − (평일 공휴일·휴무일 수 × 8시간)`, 6분 단위 반올림

## 공휴일 자동 업데이트

새로 발표되는 임시공휴일·대체공휴일은 GitHub Actions가 매일 한국천문연구원 특일정보 API를 조회해 `holidays.json`에 반영합니다. 페이지는 이 파일에 데이터가 있는 연도는 이 파일을 우선 사용하고, 없는 연도는 내장 규칙으로 계산합니다.

설정 방법:

1. [공공데이터포털](https://www.data.go.kr)에서 `한국천문연구원_특일 정보` 활용신청 (자동 승인)
2. 마이페이지에서 일반 인증키(Decoding) 복사
3. 저장소 Settings → Secrets and variables → Actions → New repository secret
   - Name: `HOLIDAY_API_KEY`
   - Secret: 복사한 인증키
4. Actions 탭 → `공휴일 자동 업데이트` → Run workflow로 첫 실행

키를 등록하지 않아도 계산기는 내장 규칙으로 정상 동작합니다. 급하게 반영해야 하는 휴무일은 해당 날짜를 '휴무'로 지정하면 바로 계산에 반영됩니다.
